# 전산업무 포털

GitHub Pages로 올려 쓰는 업무용 HTML 도구 모음입니다. 빌드 과정 없이 파일만 추가하면 됩니다.
헤더(상단 메뉴) · 좌측 메뉴 · 경로 표시 · 도구 검색 · 다크 모드는 모든 페이지에 자동으로 붙습니다.

## 폴더 구조

```
(저장소 루트)
├─ index.html              홈 (도구 카드 목록 + 검색)
├─ _template.html          새 도구 만들 때 복사할 템플릿
├─ assets/
│  ├─ menu.js              ★ 메뉴 설정 — 도구 추가 시 여기만 수정
│  ├─ layout.js            공통 헤더/메뉴 자동 생성 + 유틸(복사, 입력값 저장, SQL 하이라이트)
│  └─ portal.css           공통 스타일
└─ db/                     카테고리 폴더 (카테고리 1개 = 폴더 1개)
   ├─ merge-deleted.html   삭제건 복구 MERGE 생성
   ├─ in-clause.html       IN절 생성기
   └─ sql-mask.html        쿼리 컬럼명 추상화(난독화) · 복원
```

주소는 `https://<아이디>.github.io/<저장소명>/db/merge-deleted.html` 형태가 됩니다.
모든 경로가 상대경로라 저장소 이름이 무엇이든 동작하고, PC에서 파일을 더블클릭해 열어도 동작합니다.

## 새 도구 추가하기

1. `_template.html`을 카테고리 폴더에 복사 → 예: `db/table-diff.html`
2. `assets/menu.js`의 해당 카테고리 `items`에 한 줄 추가

   ```js
   { file: 'db/table-diff.html', name: '테이블 비교', desc: '두 테이블 구조 차이를 비교합니다.', tags: ['diff'] }
   ```
3. 커밋·푸시하면 끝. 상단 메뉴·좌측 메뉴·홈 카드·검색에 자동으로 나타납니다.

새 **카테고리**는 `menu.js`의 `categories`에 `{ id, name, desc, items: [...] }`를 추가하고 같은 이름의 폴더를 만드세요.

## 페이지에서 쓸 수 있는 공통 기능 (`window.Portal`)

| 함수 | 설명 |
|---|---|
| `Portal.persist(formEl)` | 폼 안의 `id` 있는 입력칸을 브라우저에 자동 저장·복원 |
| `Portal.copy(text, btn)` | 클립보드 복사 + 버튼에 "복사됨" 표시 |
| `Portal.highlightSql(sql)` | `<pre class="code">`에 넣을 하이라이트 HTML |
| `Portal.store.get/set(k, v)` | 페이지별 localStorage 저장 |
| `Portal.esc(s)` | HTML 이스케이프 |

자주 쓰는 CSS 클래스: `card`, `card-title`, `step`, `grid c2/c3/c4`, `field`, `hint`, `btn primary/sm`, `seg`, `check`, `msg err/ok`, `code-wrap` + `pre.code`, `table.data`.

## GitHub Pages 배포

1. 이 폴더 내용을 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment** 에서 Source: *Deploy from a branch*, Branch: `main` / `(root)` 선택.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 접속.

> 입력한 테이블명·쿼리는 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.
> 단, 공개 저장소면 **페이지 소스(도구 코드)** 는 누구나 볼 수 있으니 회사 고유 테이블명·예시 데이터를 코드에 하드코딩하지 마세요.

## 도구: 삭제건 복구 MERGE 생성

로그 테이블(`CRUD` 컬럼에 C/U/D 기록)에서 기간 내 삭제된 레코드를 찾아 원본에 되살리는 쿼리를 만듭니다.

- **입력**: CREATE TABLE 문 또는 컬럼 목록(DB 툴/엑셀 복사) → 컬럼·PK 자동 인식, 체크박스로 조정
- **기간**: `이후`(시작 일시 이상) / `사이`(시작 이상 ~ 종료 이하). 로그 일시가 DATE형인지 문자열(14/8자리)인지 선택
- **사전 작업**: 원본 백업(구조+데이터) / 구조만 복사한 새 테이블에 적재 / 복사 없음
- **최종 이력이 D인 건만**: 삭제 후 다시 등록된 키는 제외 (PK별 최신 로그 1건이 D일 때만 대상)
- **출력 순서**: ① 대상 건수·목록 확인 → ② 테이블 복사 → ③ MERGE → ④ 누락 검증 쿼리
- **DBMS별 문법**: Oracle / SQL Server / PostgreSQL 15+ (MERGE), MySQL 8+ (`INSERT … SELECT … NOT EXISTS` 또는 `ON DUPLICATE KEY UPDATE`)

## 도구: 쿼리 컬럼명 추상화

회사 테이블·컬럼명을 드러내지 않고 쿼리를 외부(AI, 커뮤니티, 협력사)에 보여줄 때 씁니다.

- **추상화**: 쿼리를 붙여넣으면 테이블 → `TB_01`, 컬럼 → `COL_01`, 스키마 → `SCH_01` 등으로 바꿉니다. 예약어·내장 함수·별칭(옵션)은 그대로 둡니다.
- **직접 수정**: 매핑 표에서 바꿀 이름을 고치거나(Enter/↑↓로 다음 칸), 체크를 풀어 원래 이름을 유지하거나, 종류(테이블/컬럼…)를 바꿀 수 있습니다. 겹치는 이름·예약어·특수문자는 빨간색으로 경고합니다.
- **사전**: 같은 이름은 항상 같은 이름으로 바뀌도록 브라우저에 저장됩니다. JSON 내보내기/가져오기, 표 복사(엑셀), 직접 추가(여러 줄 붙여넣기) 지원.
- **복원**: 외부에서 받은 쿼리나 설명 글을 붙여넣으면 사전 기준으로 원래 이름으로 되돌립니다. 사전에 없는 `COL_99` 같은 이름은 따로 알려줍니다.
- **옵션**: 바인드 변수(`:var`, `@var`, `#{var}`), 사용자 함수·패키지, 문자열 값(짧은 코드값·날짜형식 제외 가능), 주석 지우기, 동적 SQL 문자열 안 이름, 접미어 유지(`CUST_NM` → `COL_01_NM`)
- PowerBuilder 임베디드 SQL(`INTO :ls_x … USING SQLCA`), Oracle 힌트(`/*+ INDEX(A IDX) */` 안의 이름도 바뀜), CTE(WITH), MERGE, 서브쿼리 별칭을 인식합니다.

## 도구: 배치파일 블록 조립기

스크래치처럼 블록을 쌓아 Windows 배치파일(.bat)을 만듭니다.

- **쌓기**: 팔레트 블록을 클릭하면 작업 영역의 커서(파란 점선) 자리에 들어갑니다. 블록을 클릭하면 커서가 그 아래로, 조건·반복 블록을 넣으면 커서가 그 안쪽으로 갑니다. 끌어다 놓기도 됩니다(조건·반복 머리의 아랫부분에 놓으면 안쪽 맨 앞).
- **시작/끝 옵션**: 명령어 숨기기, 배치파일 폴더에서 시작(`CD /D "%~dp0"`), 관리자 권한으로 실행 / 끝나면 창 유지(`PAUSE`), 자기 자신 삭제 — 위치는 자동
- **블록**: 출력·로그 기록, 변수(정하기·계산·입력·날짜시간), 파일(복사·폴더 통째 복사·이동·이름·압축·삭제·N일 지난 파일 삭제), 조건(있으면·없으면·변수 비교·앞 명령 실패·Y/N 확인·프로그램 실행 중), 반복(파일마다·숫자·파일 줄마다), 프로그램 실행·종료, 함수(맨 아래에 따로 생성), 라벨·GOTO, 코드 직접 입력(여러 줄)
- **자동 처리**: 조건·반복 안에서 변수를 바꾸면 `SETLOCAL ENABLEDELAYEDEXPANSION` + 안쪽 `%변수%` → `!변수!`, `ECHO` 특수문자(`& | < > ) %`) 이스케이프, 빈 괄호 블록 채움
- **검증**: 빈 칸, 두 글자 이상 FOR 변수, 없는 라벨·함수, 이름 중복, 드라이브 루트 삭제, 반복 안 GOTO 등을 빨간 목록으로 (클릭하면 그 블록으로)
- **편집**: Ctrl+Z/Y 되돌리기, Delete 삭제, Ctrl+D 복제, 블록 ↔ 코드 줄 강조, 팔레트 검색, 예제 6종, JSON 내보내기/가져오기
- **저장**: ANSI(CP949, 기본) 또는 UTF-8(BOM 없이 + `CHCP 65001`), 줄바꿈 CRLF
- **배치 코드 가져오기**: 가지고 있는 .bat 를 붙여넣거나 파일로 열면(ANSI/UTF-8 자동) 블록으로 바꿉니다. 맞는 블록이 있는 문장만 블록으로, 나머지는 원문 그대로 "코드 직접 입력" 블록(원본 줄 번호 표시)으로 들어가 동작은 원본과 같습니다. 맨 위 `@ECHO OFF`·`CHCP`·`CD /D "%~dp0"`·관리자 재실행, 맨 아래 `PAUSE`·자기 삭제는 옵션으로, `EXIT /B` 뒤 라벨들은 함수 블록으로 바뀝니다. `CHOICE`/`TASKLIST|FIND` + `IF ERRORLEVEL`, `&&`/`||`, 한 줄 IF/FOR, 지연 확장(`!변수!`)도 인식합니다.
- **블록으로 못 바꾼 코드 창**: 가져온 뒤 원문 그대로 남은 곳(그리고 직접 넣은 코드)을 이유와 함께 모아 보여 주고, 질문을 적어 Claude 새 탭(`claude.ai/new?q=`, 길면 복사 후 빈 창)으로 보내거나 복사할 수 있습니다.
